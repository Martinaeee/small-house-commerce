# 1. Page Purpose


## Core Purpose


Product Detail Page (PDP) is the primary conversion page for Facebook traffic.



Customer Journey:

↓

Product Detail Page

↓

Checkout

↓

COD Order

↓

Fulfillment



PDP is not only a product information page.


It is:


- Product Sales Page
- Trust Building Page
- Lifestyle Inspiration Page
- Conversion Page



Main Objective:


Convert cold traffic users into COD orders.
