# 菲律宾 Small Space 家居选品研究

> 日期：2026-09-11
> 用途：Small House（菲律宾 COD 独立站，Facebook 获客）首发选品决策
> 口径：零售价来自菲律宾本地在售网站实测；跨境运费/汇率为规划用估算值，**已在文中标注「待核实」**，下单前必须以货代与 1688 实际报价复核。

---

## 1. 真实居住场景（需求的地基）

- **城市公寓主流面积 25–40 sqm**（菲律宾建筑设计公司对 condo 的普遍描述）；SMDC 类 micro studio 常见 **18–27 sqm**（行业常识值，待核实具体项目数据）。1BR 约 30–45 sqm。
- 除 condo 外，更大的人群住 **townhouse/rowhouse、出租房（apartment boarding）、宿舍间隔间**：无独立餐厅、厨房极小、鞋子堆门口、晾晒在窗边。品牌名 Small House 不应只打 condo，要覆盖「租房青年 + 小家庭」两个客层。
- **WFH 混合办公常态化**：本地家具商 2026 指南里，壁挂折叠书桌（fold-down desk）、可推入桌下的小椅已成单独章节。
- 菲律宾家庭观念强、访客留宿频繁 → 沙发床、折叠餐位、收纳凳（当座位用）是高频功能诉求。
- **气候约束**：全年高温高湿。板材要防潮（普通刨板易膨胀投诉），金属件防锈，面料透气可擦；浅色/木色/Japandi 风是本地设计师一致推荐的视觉方向。
- **租客约束**：大量住所禁止打孔 → 免钉/门后挂/夹缝/顶天立地/张力杆产品有天然市场，营销点直接是 "No drill, renter-friendly"。

## 2. 需求侧证据（2025–2026 在售数据）

**平台趋势**（BigSeller 2025 菲国平台报告、雨果网 2026-01 TikTok 菲站文）：

- Lazada PH 家居生活最强：**space-saving furniture、床品、墙面装饰**、厨房收纳 organizer、空气炸锅卖得最好；客群是 homemaker/家庭。
- TikTok Shop PH 家居正在起量：**smart organizers、创意厨房工具、防潮收纳、氛围装饰**；短视频演示型产品易爆。
- Shopee PH 客群是价格敏感型，靠 flash sale/低价套装；适合做清仓与引流款，不适合利润款。
- TikTok 跨境计费规则：体积重 = 长×宽×高(cm) ÷ **5000**（≤30kg；更重档位除数 6000–8000），实重与体积重取大值——**轻泡货天然吃亏，选品要控制体积**。

**本地零售商在售品类交叉验证**（Blims、Urban Concepts 的 condo/small-space 专区）：

沙发床、可伸缩餐桌、2-seater/apartment sofa、储物床/高箱床、trundle bed、壁挂折叠桌、薄鞋柜（slim shoe cabinet）、顶天立地推拉门衣柜、收纳凳、nested 茶几、墙上置物架。

## 3. 物流与成本约束（选品的硬边界）

**快递格局**（山海图 2023 梳理 + 白鲸出海 2025-07 墨腾报告解读，均为现状性事实）：

- J&T：全境覆盖、3–4 天、Shopee 系主力，单票收入连年下降（2021–2024 -35.8%）→ **对发货量大的本土仓卖家，议价窗口存在**。
- Flash：首重便宜、续重贵，TikTok 系合作；全境 5 天内；有大件部门 Flash Logistics。
- LBC：本土份额最大（电商三方件约 36%），首重贵、续重便宜，**适合重件**；1–4 天。
- 独立站的好处是可以自选承运商（平台卖家被强制平台物流）。
- 菲国 COD 专线广告口径签收率 **80–85%**，行业普遍认为家居/家具冲动单拒签率更高；拒签=双向运费+包装全损，**这是利润模型第一杀手**（BR 文档里的 Return Loss 必须按 SKU 精算）。
- Shopee 自 2025-06 起对非 Mall 卖家收 5.6% 平台运费（上限 ₱100/件）——独立站虽无此项，但要承担更高的末端议价与客服成本。

**头程两条路**：

1. **海运双清包税到门 LCL**（广州/深圳起，马尼拉清关+派送，无需进出口权）：适合家具/大件补货。行业报价为询价制、无公开价；**规划估算 ¥500–1,000/cbm（待核实，2026-09 询价）**。时效通常 10–18 天。
2. **空运/快递 COD 专线小包**：适合测款与轻小件，广告口径 4–10 天签收；**规划估算 ¥25–45/kg（待核实）**。

**末端费用规划值（待核实，向 J&T/Flash/LBC 拿卖家协议价）**：NCR 首 kg ≈ ₱55–95、外省 ≈ ₱120–180，续重 ₱20–45/kg；超尺寸/重件加超重费，LBC 走 cargo 更划算。

**推导出的选品物流红线**：

- 单件实重 ≤ 8kg、最长边 ≤ 100cm 为舒适区（普通快递可发，NCR 运费压在 ₱150 内）。
- 体积重 ÷5000 后不能显著大于实重——**可平板包装（flat-pack）是第一筛选条件**。
- 拒收高风险组合要回避：玻璃/陶瓷、大面积易损镜面、需复杂组装且无视频说明的件、客户收到后「与预期尺寸不符」的大件。
- 首批不上沙发床/床垫/大柜：体积重爆炸、逆向成本不可承受。

## 4. 选品评分模型（建议固化到选品 SOP）

每个候选 SKU 按 1–5 分打分，加权后 ≥3.8 才进首批：

| 维度 | 权重 | 达标线 |
|---|---:|---|
| 需求证据（平台销量/视频播放/本地在售价差） | 25% | 至少 2 个证据源 |
| 单件经济（毛利额，非毛利率） | 25% | 预期单件贡献毛利 ≥ ₱180 |
| 物流适配（实重/体积重/可平板包/破损率） | 20% | ≤8kg、体积重不超实重 30% |
| 视频演示性（3 秒看懂 before/after） | 15% | 免工具/免钉/一秒变形优先 |
| COD 韧性（冲动退货风险低、尺寸预期清晰） | 15% | 尺寸图+参照物，非玻璃非大件 |

一票否决：非平板包装的泡货、玻璃陶瓷为主、组装超过 15 分钟、供应商无 EN71/承重报告（椅子/桌类必须有承重数据，菲律宾客户体重偏大，椅子类事故=差评+拒收）。

## 6. 单品经济模型（示例，按待核实规划价）

规划汇率假设：¥1 ≈ ₱7.8（待核实）。

**A. 引流款：折叠电脑桌，零售 ₱499（包邮 NCR）**

| 项 | 金额 |
|---|---:|
| 拿货 ¥28 | ₱220 |
| 头程（空运小包估 ¥8/件，或海运更低） | ₱60 |
| 包装+贴单 | ₱25 |
| 末端运费（NCR 协议价估） | ₱85 |
| COD 回款费 ~2.5% | ₱12 |
| 退货损失预提（按签收 90%、拒收损失 ₱210/单计 ≈ 10%×210） | ₱21 |
| **履约+货总成本** | **₱423** |
| 单件可用于广告+净利的空间 | **₱76** |

→ 引流款不靠单件赚钱：目标是 **AOV ≥ ₱999（买 2 件或搭售收纳件）**，二件边际运费极低，广告 CPA 可承受 ₱150–250。

**B. 利润款：超薄翻斗鞋柜，零售 ₱2,999（NCR 包邮，外省补运费差价 ₱150）**

| 项 | 金额 |
|---|---:|
| 拿货 ¥130 | ₱1,015 |
| 海运分摊（约 0.06cbm，按 ¥800/cbm）+ 清关派送估 | ₱120 |
| 包装 | ₱60 |
| 末端（约 9kg，协议价估） | ₱230 |
| COD 费 2.5% | ₱75 |
| 退货预提（签收率 88%，拒收损失约 ₱750×12%） | ₱90 |
| **合计成本** | **₱1,590** |
| **单件毛利额（广告前）** | **₱1,409（47%）** |

→ 可承受 ₱500–700 的 Facebook CPA，仍有 25%+ 净利空间。这是应该投广告的「英雄款」。

## 7. 定价与组合策略

- 三档价格锚：₱299–599 引流（Tier 1）／₱999–1,999 升级／₱2,499–3,999 英雄款（Tier 2）。
- **场景化捆绑提 AOV**：Entry Set（门后鞋架+折叠凳+薄鞋柜）、Kitchen Set（水槽架+沥水架+挂桶）、Studio Set（电脑桌+床边挂袋+收纳箱×3）。捆绑后运费边际下降，毛利率提升 8–15pct。
- 包邮门槛设在 ₱999（NCR），外省阶梯运费透明展示——与 BR 文档的 Shipping Rate Rules 表对应。
- 跟卖款定价卡本地零售价 60–70%（如薄鞋柜对标本地中位 ₱3,745 定价 ₱2,999），但**不做最低价**：靠尺寸教学内容、组装视频、承重演示、英文+Taglish 客服建立信任。
- 材质标注防潮（moisture-proof / rust-proof）、renter-friendly、no-drill 作为全站统一卖点。

## 8. 验证与上架节奏

**第 0–2 周（零库存验证）**

1. Facebook Ad Library + TikTok 搜 #smallspaceph #condolivingph #toktokorganizing，记录高播放视频对应品与评论区抱怨。
2. EchoTik / Kalodata 免费档拉 PH home 类目销量榜交叉验证。
3. 对候选 20 SKU 做 Facebook 落地页/Pixel 测试：每个 SKU 3 条素材、小预算（₱300–500/天）测加购与 COD 表单提交成本。
4. 同步向 3 家以上货代询头程价（¥/cbm、¥/kg、双清是否含 VAT）、向 J&T/Flash/LBC 询卖家协议价——**替换本文全部「待核实」数字**。

**第 3–6 周（空运小包，30–50 件/胜出品）**

- 真实签收率、拒收原因分类、客服问题（组装难/尺寸误会）回流到商品页。
- 签收率 <80% 的 SKU 直接淘汰；签收 ≥90% 且 CPA 达标者进入海运补货。

**第 7–12 周（海运 + Tier 2 英雄款）**

- 马尼拉仓备 2–3 个英雄款（鞋柜/折叠桌/储物凳），NCR 主打、外省运费门槛清晰。
- 上线场景化 bundle，按 BR §13 的利润公式逐 SKU 看 Realized Profit（Revenue − 产品 − 运费 − COD − 支付 − 广告 − 退货）。

## 9. 红线清单

- 不碰玻璃、陶瓷、大镜面；不碰 >12kg/最长边 >120cm；不碰必须打孔安装而无免钉方案的品。
- 椅凳类必须要供应商承重测试数据，商品页标注限重。
- 首批不碰沙发床/床垫/大衣柜。
- 任何 SKU 广告前毛利额 <₱180 不投流，只做自然流量/凑单。
- 拒收率连续两周 >15% 的地区/品类，先停投查因（尺寸图、派送时效、竞品差评），不硬扛。
