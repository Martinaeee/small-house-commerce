# 商品卡 V2：变体独立双图与紧凑选择

日期：2026-10-11
状态：视觉方向 A 与本设计已审阅；具体实施计划待用户审阅，尚未开始实现或发布。

## 1. 目标与现状

用户希望商品卡的封面图与鼠标悬停图可以明确设置，每个真实变体拥有独立配置；卡片下方只展示商品变体选择，不混入套餐购买控件，长选项不再把卡片撑高，桌面悬停反馈更清晰。

上一轮已在本地实现统一商品卡、真实加购、防重复提交、选款后的图片/价格/库存联动、手动场景图及无购买副作用的后台预览，但目前仍有三处差距：

- 卡片封面取有效图库的第一张 IMAGE，设封面会涉及图库排序，并不是独立的卡片配置。
- 精确变体图库不存在时，媒体解析仍会回退到选项值或共享图库。
- 文字选项全部换行展示；整卡上移仅约 2px，反馈较弱。

本设计修正这些差距，不将上一轮本地验收等同于本轮已实现，也不改变详情页图库的既有作用域规则。

## 2. 已选视觉方向 A

采用 Castlery 式清晰的方形图片与简洁选项布局，结合更明显的整卡悬浮反馈，保留 LUWAG 原有字体与品牌配色，不复制参考站商品图片或促销文案。

- 图片区域调整为 1:1；白底封面完整居中展示家具，避免裁掉桌腿、扶手等主体。
- 悬停图填满相同图片框；图片框尺寸始终不变。
- 桌面精确指针悬停整卡时上移约 6px，并增加柔和、可辨认的阴影；不放大整张卡片，不挤动相邻商品。
- 图片区域悬停才切换图片；悬停价格、选项或按钮只产生整卡反馈，不触发换图。
- 切换约 180–220ms；新图加载完成前保留封面，离开图片区域立即恢复封面。
- 图片加载失败继续保留封面；悬停图为空或与封面相同，不产生无意义切换。
- 触屏设备不浮起、不依赖 hover，首次点图片正常进入详情页；键盘焦点清晰，reduced-motion 禁用位移与动画。
- 保留商品名称、真实评分、价格/有效划线价、必要运营徽标与 Add to Cart；折扣信息避免在图片与价格区重复强调。

## 3. 每个变体独立配置双图

后台为每个真实变体提供两个明确槽位：

1. **卡片封面图**：该变体在商品卡图片区域默认展示的图片。
2. **卡片悬停图**：鼠标进入图片区域时展示的图片，可为空。

单款商品同样保存到其真实变体，只是在后台显示为一组“卡片图片”，不要求运营理解默认变体的内部结构。

- 可单独上传图片，也可从已有商品图库选择；两个槽位只接受图片，不接受视频。
- 从图库选择时保存该变体自己的图片 URL/Alt 快照，不建立“修改共享图就自动修改所有变体”的继承关系。
- 修改某个变体只影响该变体，不联动其他尺寸、颜色或款式。
- 卡片配置独立于详情页图库：不通过重排图库实现，不因上传卡片图而把详情页原有共享图库替换成仅两张图。
- 因此推荐在变体上保存窄的结构化卡片图片配置，而不是继续借用图库第一张或把卡片专用图片加入详情图库作用域。
- 省略配置字段表示不修改；明确清空表示移除对应槽位；更换变体身份不会把上一变体的配置套到新变体。
- 保存继续使用既有目录版本与冲突保护，不能为设置图片重建 SKU、改变库存或丢失其他草稿字段。

前台选中完整变体组合后，只读取该变体的卡片双图；没有悬停图就只显示封面，没有专属封面就显示缺图状态，不借用共享图、其他颜色或其他尺寸的图片。

未选完整组合时不猜测实际购买 SKU，也不展示另一变体的悬停图；多款商品由运营设置有效的默认展示款式，使初始卡片具有明确图片与可理解的选项状态。

## 4. 后台设置方式

在商品编辑中增加聚焦的“卡片展示”设置区，按真实变体列出：

| 变体 | 卡片封面图 | 卡片悬停图 | 配置状态 |
|---|---|---|---|
| 颜色 / 尺寸 / 款式组合 | 上传 / 从图库选 | 上传 / 从图库选 / 清空 | 完整 / 缺封面 |

- 使用小缩略图与紧凑操作，复用已有上传能力，不再新增一长排 URL 输入框。
- 提供默认展示款式选择及只读预览；上传或保存未结束时保持现有锁定行为。
- 选项值缩略图只用于选项外观，不自动当成所有相关 SKU 的卡片封面。
- 新卡片设置入口接替旧图库的“设为场景图”按钮，避免出现两个竞争的卡片图片来源；旧标记数据保留，不擅自删除，新卡片配置不从旧标记自动继承。
- 草稿可以缺图，准备上架时明确列出缺少专属封面的可售变体；不能自动给全部变体套上共享图并宣称已配置完成。

## 5. 只展示商品变体选择

复用详情页真实的颜色、尺寸、材质和款式数据及 SKU 匹配规则，但卡片使用紧凑外观，不搬入完整详情页购买表单。

- 没有两个及以上可选变体时，不显示多余的变体选择区域。
- 颜色优先显示色点；有图片呈现的款式显示小缩略图；短尺寸值显示紧凑按钮。
- 每组默认只占一行，可见数量按实际卡片宽度决定，不把桌面数量硬塞到移动双列卡片。
- 超出空间显示 **+N**；点击后桌面打开选择面板，手机打开底部面板，展示该组全部选项。
- 长文字在面板中完整换行；卡片仅显示紧凑的选中摘要，完整名字对键盘和辅助技术同样可读。
- 选项很多时面板支持搜索；搜索不会删除已有选择，选中项不会因为不在前几个值中而失去可见状态。
- 选择后同步主图、悬停图、价格、划线价及库存；不兼容组合不可选，缺货状态清晰，仍保留既有 Save for Later 语义。
- 面板可键盘操作、关闭后恢复焦点；加购期间禁止再选款。

**不展示**套餐购买模块、数量加减、推荐组合或详情页多行录单表单。

“不展示套餐控件”不等于下架独立售卖的 Bundle 商品，也不等于删除 Bundle 的颜色/尺寸等真实变体；不靠 label 中是否包含 bundle/set 等文字猜测并删除真实 SKU。

## 6. 所有入口与购买安全

首页、类目、搜索、集合、相关推荐、最近浏览继续共用同一商品卡，保留各入口既有网格、筛选和排序。

- Add to Cart 仍提交所选真实 SKU，数量 1；Bundle 仍只提交其虚拟 SKU，不在卡片中拆成组件加购。
- 保留同步重复提交锁、确认顺序、请求快照和成功/失败反馈；价格或缺货逻辑不以视觉变化为理由重写。
- 商业事件只在真实动作成功后按既有规则发出，不因打开“更多选项”或悬停图片发出购买事件。
- 选择与悬停不新增 PDP/媒体 API 请求，仍使用列表批量下发的轻量卡片投影；实际点击图片/标题才导航。
- 后台预览可显示配置结果，但禁用购买、变体修改、导航与商业埋点，不需要 CartProvider 才能渲染。

## 7. 现有商品与上线边界

现有商品可能只有共享图库，没有每变体的独立卡片配置；本轮不能通过默默复制或继承共享图掩盖缺配置。

实施与发布前需盘点可售变体的封面和默认展示款式是否齐全；缺图要明确报告、补齐或由运营决定不上架，不能未经授权修改现有商品状态或生产图片数据。

- 不提交、push、merge、创建 PR 或部署，除非用户另行授权。
- 不操作生产数据，不触碰 protected backend/uploads，不重启 3000/3001。
- 与营销线协调共享数据库/schema/generate 窗口；测试使用本轮独立数据库与运行副本，不向其他库自动应用待执行迁移。
- 不改变金额、库存、Bundle 组件计算、营销归因或费用逻辑。
- 不恢复暂缓的首页完整外壳、Header/Footer 编辑或公告富文本倒计时任务。

## 8. 验收标准

- 至少两个变体配置完全不同的封面/悬停图，来回选择不会共享、串图或改变详情图库。
- 清空悬停图、缺少封面、加载失败、延迟加载、切换变体和保存冲突均有明确行为。
- 375/768/1440 下长标签、两组选项与大量款式不会撑破卡片；全部值可访问，Add to Cart 可触达。
- 桌面整卡浮起明显但网格不抖动；图片区域之外不换图；触屏首次导航与键盘/reduced-motion 正常。
- 真实购物车回读验证 SKU/数量；双击只有一次请求，失败后可重试，不改其他卡片或主 PDP 选择。
- 后台预览无购买副作用，完整类型检查、测试、lint、隔离生产构建及真实浏览器通过后，仍停在本地验收。
